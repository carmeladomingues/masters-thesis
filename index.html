Invisible Ecosystem — System Architecture

Domestic violence support system · P0 to P4 · Portugal · v2 — updated

What changed in v2: The LLM now responds directly inside the platforms she already uses (ChatGPT, Google, TikTok, Reddit) — no redirection to a site in P0/P1. The conversation happens where she already is. The site only enters from P2 onwards, when she is ready for more structured support. iOS Shortcuts replace the site diary in P1 — she saves notes natively on her iPhone, with an innocent name, no new app needed.

Trained AI model (LLM fine-tuned on IPV data) running invisibly across all phases — detects patterns in natural language, classifies user phase (P0–P4), adapts content and recommendations in real time. Never visible to the user.

Where it happens
Inside existing platforms ChatGPT · Google · TikTok comments/search · Reddit responses. The LLM is the layer on top — she never leaves the platform she opened.
iOS native storage updated iOS Shortcut saves her thoughts to iPhone Notes, Voice Memos, or a custom named folder. Siri activates it. No new app, no site, no account.
Site — Action Mode Smart curator activates. Recommends specific Portuguese initiatives based on abuse type, location and phase.

Detects escalation. Introduces site for the first time. Activates smart curator. Surfaces emergency contacts. Connects Apple Watch SOS if set up.
